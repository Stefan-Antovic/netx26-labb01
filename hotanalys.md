# Hot   
1. Ransomware det vill säga utpressning som kan kopplas till exempel e-post och Microsoft 365. Detta innebär att hotaktörer får tag på information som dem kan använda som en över hand på företaget.
2. Data Breach detta kan kopplas till HR-system, då hotaktörer kan få tag på namn och generellt uppgifter om personer.
3. Förlust/stöld av mobilen detta kan innebära att hotaktören kan få tag på känslig information. Allt från bankuppgifter, bilder, mail osv.

# Sårbarheter   
1. Om företaget inte har 2FA på sina system så blir det lättare för hotakötrer att komma in, avsaknad 2FA är sårbarheten.
2. Återanvända lösenord, likadant där om man använder samma lösenord i dem flesta system allt från mail till sociala medier så kan kotakörer komma in i alla system med ett knapptryck.
3. Ingen skärm lås detta kan kopplas till mobilerna i företaget om mobilen blir stulen eller förlorad så kan vem som helst komma in i telefonen. Detta kommer innebära att hotaktören kan se allt som finns på telefonen utan några bekymmer.

# Skyddsåtgärder
1. 2FA detta bör finnas på varje system då det blir svårare för personer att komma in.
2. Skärmlås eller generellt lås på enheter ska också finnas då det blir lite svårare för hotaktörer eller generellt någon att komma in på datorn.
3. Brandvägg bör finnas på till exempel HR-Systemet då det finns väldigt mycket information om personer. Detta gör det mycket svårare för hotaktörer att komma in.

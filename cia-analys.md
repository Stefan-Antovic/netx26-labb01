# Ransomware  

# Confidentiality   
Hotaktörer stjäl/kopierar datan som dem sedan använder för att hota med. Ett exempel är att hotaktörertar sig in i företagets nätverk genom att tex phising mejl sedan letar dem efter värdefull data som tex personuppgifter. Efter detta kopierar/stjäl dem datan som sedan leder till att hotaktörerna krypterar deras datorer. Detta i sin tur leder till att de hotar att läcka/sälja datat om lösensumman inte betalas.   

# Integrity   
Ransomware påverkar integrity genom att innehållet inte längre är i sitt ursprungliga skick och detta efter att krypteringen gör om filens innehåll. Ett exempel är att personerna i företaget inte kan se någonting på sina datorer eller att innehållet är oläsbart.   

# Availability  
Ransomware påverkar tillgängligheten enormt då ingen kommer kunna komma åt sina system/filer då dem är krypterade. Ett exempel är att de anställda på företaget behöver hantera några uppgifter om kunder och då kan de inte göra det då allt är antingen nedstängd eller suddigt.
